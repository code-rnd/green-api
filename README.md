# GREEN-API чат

Текстовый чат для Telegram через [GREEN-API](https://green-api.com/en/telegram/docs/api/). Отдельного сервера у проекта нет: страница в браузере сама отправляет сообщения и забирает новые из очереди.

## Как запустить у себя

Нужен Node.js 22. В папке проекта:

```bash
npm install
npm run dev
```

В терминале появится адрес, обычно [http://localhost:5173/](http://localhost:5173/).

На экране входа укажите адрес API (поле уже заполнено `https://api.green-api.com`), ID инстанса и токен из кабинета GREEN-API.

В кабинете инстанс Telegram должен быть авторизован, поле webhook пустое, уведомления о входящих включены. Иначе новые сообщения в чат не придут.

Переписка живёт, пока открыта вкладка. Обновите страницу - снова увидите экран входа, чаты пропадут.
